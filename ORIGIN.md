Original check-manifest builds two distributions, lists VCS files, copies sources, changes environment/current directory, optionally appends MANIFEST rules and normalizes/deduplicates file lists. The new tool accepts an already existing archive and independently trusted explicit manifest. It preserves all observed duplicate/type/path evidence, validates supported real structures/payload boundaries and performs an explicit path-set comparison without building, extracting or executing targets. Generated-file policy is exact and caller-supplied rather than a inherited blacklist/glob ignore. Upstream whole-platform behavioral equivalence is not claimed.
